# Beego

Example [Beego](https://github.com/beego/beego) app. Beego is a full-featured Go framework for building web applications and REST APIs.

## Deploy settings

| Field | Value |
| --- | --- |
| Build | Railpack |
| Project directory | `/` |
| Install command | leave empty |
| Build command | leave empty |
| Start command | leave empty |
| Application port | `8080` |
| Health check path | `/` |

## <a name="dev"></a>Run locally

```bash
# start the app
go run main.go
```
